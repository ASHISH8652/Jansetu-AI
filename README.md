# JanSetu AI 🇮🇳

### Civic Service Copilot powered by Google Gemini

> **Turn a citizen's problem into an actionable public-service request.**

JanSetu AI is a human-review-first civic service copilot designed for
**AI for Digital Public Infrastructure & Governance**.

It allows citizens to describe civic problems in natural language and,
optionally, provide photo evidence. Google Gemini analyzes the input and
converts it into a structured, actionable service request.

---

## 🚀 Problem

Citizens often know what problem they are facing, but they may not know:

- Which department should handle it?
- What category should they select?
- How urgent is the issue?
- What information should be provided?
- How should the complaint be written?

Traditional service portals can require citizens to understand government
service terminology before submitting an issue.

**JanSetu AI starts with the citizen's language.**

---

## 💡 Solution

JanSetu AI acts as an AI-powered civic service copilot.

A citizen can provide:

1. Preferred language
2. Locality / area
3. Natural-language description of the issue
4. Optional photo evidence

The system then generates:

- Intent
- Suggested department
- Service category
- Urgency level
- Plain-language summary
- Missing information
- Suggested next steps
- Visual evidence observations
- Editable service request
- Simulated reference ID

The citizen can review and edit the generated request before using it.

---

## ✨ Key Features

### 🗣️ Natural Language Civic Reporting

Citizens can describe problems in simple language instead of navigating
complex service categories.

Example:

> "Garbage has not been collected from our street for the last four days.
> The waste is piling up and there is a bad smell."

JanSetu AI converts this into a structured service request.

---

### 🌐 Multilingual-Ready

The interface supports:

- English
- Hindi
- Odia
- Hinglish

The architecture is designed to support broader Indian-language civic
interactions.

---

### 📸 Multimodal Civic Evidence

Citizens can optionally upload:

- JPG
- PNG
- WEBP

Images can provide additional context for issues such as:

- Potholes
- Road damage
- Garbage accumulation
- Fallen trees
- Public infrastructure problems

Google Gemini can analyze the text and visual evidence together.
